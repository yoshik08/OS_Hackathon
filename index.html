05 / ENGINEERING SPECIFICATION

HOW IT WORKS & ARCHITECTURE

RIGOROUS HARDWARE ISOLATION • DEMAND-PAGED HEAP SATURATION • ZERO BROWSER CRASH GUARANTEE

01 // CONCURRENCY

Dedicated Worker Threads

Spawns background Web Workers via dynamic Blob URLs. CPU intensive arithmetic executes on isolated OS kernel threads, guaranteeing 60 FPS UI responsiveness on the browser's main event loop.

02 // MEMORY PAGING

Real Physical Allocation

Overcomes virtual memory lazy zero-page optimizations by iterating across 4096-byte memory page strides with non-zero byte writes, forcing real physical host RAM commitment.

03 // TELEMETRY

High-Res Jitter Scoring

Samples throughput every 500ms using performance.now(). Evaluates variance coefficients (CV) and latency spikes to calculate a 0-100 system stability rating.

04 // SAFETY LIMITS

Deterministic Deallocation

Guaranteed safe termination: Emergency Stop instantly issues worker.terminate(), truncates TypedArray references, and drops allocated MB counter to 0.
