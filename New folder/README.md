# coding-practice-pack

A small collection of practice exercises across Python, Java, JavaScript, and Linux.
Use these as a starting point: run them, improve them, add tests, and document what you learn.

## Contents
- `python/` — beginner algorithms and utilities
- `java/` — basic algorithms and OOP practice
- `javascript/` — language fundamentals
- `linux/` — shell practice scripts
- `notes/` — topic checklists

These are intentionally small learning examples, not production-ready software.
