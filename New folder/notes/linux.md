# linux practice checklist

- [ ] `pwd`, `ls`, `cd`
- [ ] `cp`, `mv`, `rm`, `mkdir`
- [ ] input/output redirection
- [ ] pipes and filters
- [ ] permissions with `chmod`
- [ ] processes with `ps` and `kill`
- [ ] `grep`, `find`, `wc`
- [ ] file descriptors: `dup`, `dup2`
- [ ] process creation: `fork`
